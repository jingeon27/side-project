# 웃긴순간: 그룹 커뮤니티

2026-10-19 제품 방향. 기존 기간제 사진 대회에서 상시 커뮤니티로 바꾼다.

## 사용자 경험

친구들과 웃긴 사진·동영상·합성을 모아 두고, 아무 때나 올리고 반응하는 그룹이다. 카페나 게시판처럼 글이 쌓이고 이전 글도 계속 볼 수 있다.

- 홈: 가입한 모든 그룹의 게시물을 전체 최신순으로 보여 준다. ‘이달의 인기’도 함께 제공한다.
- 탐색: 로그인 없이 이름으로 그룹을 찾고 공개 사진·동영상을 감상한다.
- MY: 내 프로필, 가입한 그룹, 새 그룹 만들기.
- 그룹: 날짜 없이 공개·비공개를 선택해 만든다. 제목·내용과 사진 또는 동영상을 여러 번 올릴 수 있다.
- 초대: 공개 그룹은 바로 가입하고 비공개 그룹은 그룹장·부관리자의 수락을 기다린다. 초대 공유는 모든 멤버, 재발급은 그룹장만 가능하다.
- 반응: 좋아요 수와 내 반응을 보여 준다. 이달의 인기는 KST 이번 달 게시물을 좋아요순으로 선정한다.
- 관리: 작성자는 자기 게시물, 관리자(그룹장·부관리자)는 그룹의 다른 게시물도 삭제할 수 있다. 그룹장은 부관리자·멤버를, 부관리자는 일반 멤버를 내보낼 수 있고, 그룹장이 아닌 멤버는 직접 그룹을 나갈 수 있다(그룹장은 양도한 뒤 나간다).

사진·동영상·합성을 모두 환영한다. 그룹에는 만료일이나 행사 종료 상태가 없고 한 사람의 게시물 개수도 제한하지 않는다. 업로드 티켓의 만료는 전송 보안을 위한 것이며 게시물·그룹의 수명과 관계없다.

## 접근과 미디어

공개 그룹은 익명으로 게시물·미디어·댓글을 읽고 로그인 후 바로 가입한다. 비공개 그룹은 그룹장에게 신청하고 수락된 뒤 내용을 본다. 그룹 이름·공개 여부·멤버 수는 탐색할 수 있지만 비공개 사진·댓글은 노출하지 않는다. 댓글·좋아요·글쓰기는 가입한 멤버만 사용한다. 공개 그룹은 검색 엔진에 canonical·JSON-LD·사이트맵을 제공한다.

브라우저가 저장소에 직접 올리며 서버는 파일을 읽거나 변환하지 않는다. 사진은 JPEG·PNG·WebP 10MB, 동영상은 MP4·WebM 100MB까지 받고 동영상 5분 제한은 브라우저가 확인한다. 사진·동영상의 EXIF·위치 메타데이터는 일부러 제거하지 않는다. 매 파일 요청에 공개 범위·멤버십을 확인한 뒤 60초 서명 주소로 보내 저장소가 Range 재생·탐색을 처리한다.

## 화면과 기술

Next.js 16 + Apollo Client + schema-first GraphQL + PostgreSQL, Expo WebView 앱을 사용한다. 웹은 휴대폰부터 최대 1440px까지 대응하며 피드는 1열, 탐색 목록은 1·2·3열이다. 네이티브 앱은 로그인·공유·복사·햅틱·딥링크를 연결한다.

인증·최신·인기·그룹 정보의 조회 맥락과 Suspense 경계를 분리한다. 서버 상태는 Apollo에 두고 폼은 RHF/Zod, 오버레이는 overlay-kit을 쓴다. 고정 메뉴는 JSX에서 선언한다.

## 검증할 가설

- 친구와 함께 웃긴 순간을 모아 두려는 수요가 있는가.
- 기간 제한 없는 등록과 인기 게시물이 재방문으로 이어지는가.
- 초대 링크 공유가 새 멤버 유입으로 이어지는가.

실사용·전환율·재방문 성과는 아직 측정하지 않았다. 초기 이용자를 모집한 뒤 가입→첫 게시물→좋아요→재방문의 흐름을 관찰한다.

## 데이터 전환

기존 대회·사진 테이블은 보존하고 기존 사진·좋아요를 새 게시물로 이관한다. 숨김과 작성 시각도 유지한다. 새 글에는 대회 ID·마감일·1인 1장 제약을 두지 않는다. 기존 대회 URL/API는 이전 링크를 위해 유지한다.
