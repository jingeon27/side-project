# 쇼츠 오디오 출처

## 한국어 대화체 화자

`ko-casual-male.flac`, `ko-casual-female.flac`, `ko-comment-male.flac`는 VoxCPM2의 Voice Design으로 만든 가상 화자 음성이다. 세 화자 모두 “처음엔 그냥 지나쳤는데 다시 보니까 좀 재밌더라고요. 여기 한번 보세요.”를 읽었다. 각각 담백한 서울말 남성, 밝은 여성, 가벼운 남성 목소리를 지정하고 시드 1901, 784, 643으로 합성했다. 원본 PCM을 무손실 FLAC으로 저장해 이후 컷의 음색 기준으로 사용한다. [VoxCPM2 모델 카드](https://huggingface.co/openbmb/VoxCPM2)
