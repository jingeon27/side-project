# 장면 | 한국어 AI 창작 스튜디오

영화, 드라마, 짧은 애니메이션, 웹툰과 소설을 만들고 편집하는 독립 프로젝트입니다. 소개는 `/`, 작업실은 `/studio`에 있습니다. 기본값은 **API 키 없는 로컬 생성**입니다.

## 실행

현재 로컬 모델 실행은 **Apple Silicon Mac, Python 3.11, 메모리 32GB 이상 권장** 환경을 대상으로 합니다. 실제 검증 장비는 M5 Pro 48GB입니다. 처음 모델을 다운로드하고 변환할 때 약 60GB 이상의 여유 공간과 인터넷 연결이 필요합니다. 설치 후 생성은 오프라인으로 실행합니다.

저장소의 Node.js 24와 Yarn 4.17.0을 사용합니다. 저장소 루트에서 실행합니다.

```sh
yarn install --immutable
cp projects/story-studio/apps/web/.env.example projects/story-studio/apps/web/.env.local
yarn workspace @side/story-studio local:setup
yarn workspace @side/story-studio dev
```

[소개](http://127.0.0.1:3400), [작업실](http://127.0.0.1:3400/studio), [목소리 학습](http://127.0.0.1:3400/studio/voices), [실제 생성한 한국어 애니메이션](http://127.0.0.1:3400/studio?demo=1)

예시 원고 편집과 이미 생성한 예시 영상 재생에는 모델 설치가 필요하지 않습니다. 모델 준비 전에는 생성 버튼이 비활성화됩니다. 운영용 빌드는 `yarn workspace @side/story-studio build`, 실행은 `yarn workspace @side/story-studio start`입니다.

## 모델과 제작 순서

| 역할                                  | 로컬 모델                                          | 실행 방식                 |
| ------------------------------------- | -------------------------------------------------- | ------------------------- |
| 한국어 원고, 이어쓰기, 시각 묘사 번역 | Qwen3.8-27B의 mlx-community 4비트 변환본           | MLX VLM                   |
| 이미지 컷과 짧은 영상                 | 공식 Wan2.1-T2V-1.3B의 MLX 8비트 변환본            | MLX Video                 |
| 한국어 목소리                         | Qwen3-TTS-12Hz-1.7B-CustomVoice의 MLX 4비트 변환본 | 기본 음색 9종과 말투 선택 |
| 목소리 가중치 학습                    | Qwen3-TTS-12Hz-1.7B-Base의 MLX 4비트 변환본        | 로컬 QLoRA 미세학습       |
| 자막, 음성, 장면 합치기               | 모델 계산 없이 로컬 ffmpeg                         | H.264 MP4, AAC 음성       |

1. 한국어 아이디어, 인물과 스타일을 입력해 원고를 만듭니다
2. 장면별 한국어 음성을 먼저 생성합니다
3. 이미지나 짧은 영상을 필요한 장면에 생성합니다
4. 내보내기에서 한국어 음성과 자막을 넣은 MP4, 말풍선을 넣은 웹툰 PNG, 원고 또는 JSON 백업을 저장합니다

한 번에 1~8개 장면, 컷, 장을 작성하고 이어쓰기로 작품당 최대 80개까지 확장합니다. 장편은 회차별로 쓰는 방식입니다. 영화 수준의 인물 일관성, 립싱크, 긴 연속 영상이나 전문 편집 타임라인은 포함하지 않습니다. 한국어 글자와 말풍선은 앱이 합성하므로 시각 모델의 문자 생성에 의존하지 않습니다.

모델과 런타임은 [모델 revision](apps/web/scripts/local/models.json), [Python 의존성](apps/web/scripts/local/requirements.txt)에 고정했습니다. 공식 모델 설명: [Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B), [Qwen3-TTS](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice), [Wan2.1](https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B). MLX 변환본은 커뮤니티 배포이며 공식 원본과 구분합니다.

## 목소리 학습

기존 설치에서는 아래 명령으로 약 2.3GB의 공개 Base 모델을 추가로 준비합니다. 기본 전체 설치에도 포함됩니다. API 키나 외부 음성 서비스는 필요하지 않습니다.

```sh
yarn workspace @story-studio/web local:setup:voice
```

1. 작업실의 **목소리 학습**에서 목소리 이름을 만듭니다
2. 같은 사람의 녹음 2~50개와 녹음에서 실제로 읽은 대본을 등록합니다
3. 녹음과 대본을 저장하고 반복 횟수를 정한 뒤 **새 학습 시작**을 누릅니다
4. 완료 후 작업실의 장면에서 목소리를 선택하고 한국어 음성을 생성합니다

각 녹음은 1~30초, 10MB 이하입니다. WAV, MP3, M4A, FLAC, OGG와 WebM을 로컬에서 24kHz 모노 WAV로 변환합니다. 긴 녹음을 자동으로 자르지 않으므로 대본과 음성이 어긋나지 않습니다. 배경 음악과 다른 화자가 없는 자료를 사용하세요. 파일 저장이 일부 실패해도 대본과 녹음 ID를 유지하고 같은 요청을 재시도해 중복을 피합니다.

이 기능은 샘플 음성을 참조하기만 하는 복제가 아닌 **실제 QLoRA 가중치 미세학습**입니다. 4비트 기본 모델은 고정하고, talker와 code predictor의 attention q/v에 rank 8, alpha 16 어댑터 1,810,432개 파라미터를 학습합니다. 전체 17억 파라미터를 재학습하는 방식은 아닙니다. 화자 특징도 함께 저장해 이후 합성에서는 참조 녹음을 다시 넣지 않습니다. 한국어 추론 prefix, 이전 프레임의 16개 코드와 잔여 코드 teacher forcing을 사용하며, MLX Audio 0.6.5 인터페이스에 맞춘 앱 자체 학습 구현입니다. [공식 Qwen SFT 구현](https://github.com/QwenLM/Qwen3-TTS/tree/main/finetuning)과 실행 환경은 다릅니다.

첫 단계, 5단계마다, 마지막 단계에 어댑터와 AdamW 계산 상태를 원자적으로 저장하고 마지막 체크포인트 두 개를 보관합니다. 화면을 나가거나 웹 서버를 재시작해도 시작한 Python 학습은 계속될 수 있습니다. **학습 중단** 후 **이어서 학습**을 선택하면 저장된 지점부터 진행합니다. 컴퓨터가 종료되면 자동으로 계산을 재시작하지 않습니다. 녹음이나 대본이 바뀌었거나 기본 모델 revision이 다르면 이어서 학습하지 않고 새 학습을 요구합니다. 학습 중에는 다른 로컬 모델 생성을 동시에 실행하지 않습니다.

실제 M5 Pro 48GB에서 합성 음성 두 개로 학습, 중단, 체크포인트 재개, 총 6단계 완료 후 새 프로세스에서 8.64초 한국어 합성을 확인했습니다. 이 실행의 MLX 최대 할당은 5.69GiB였습니다. 이 수치는 이 두 짧은 녹음의 결과이며 큰 데이터셋의 상한이 아닙니다. 합성 자료의 동작 검증이며 사용자의 목소리 유사도나 발음 품질을 검증한 결과는 아닙니다. 손실 값은 서로 다른 녹음 사이의 품질 비교 지표로 사용하지 않습니다.

기본 음색 9종은 소희, 라이언, 에이든, 세레나, 비비안, 푸, 안나, 에릭, 딜런입니다. 차분함, 자연스러움, 밝음, 단호함의 말투를 선택할 수 있습니다. 한국어 기본값은 소희이며 다른 언어 기반 음색의 한국어 품질은 같다고 보장하지 않습니다.

## 성능과 자원 사용

큰 부하는 웹 서버보다 로컬 영상 모델 계산에서 발생합니다. 영상은 짧은 원본 프레임을 만든 후 요청한 장면 길이로 늘립니다. `빠른 초안`은 낮은 해상도와 적은 생성 프레임을 사용하므로 움직임의 세밀함과 화질에 차이가 있습니다.

| 13초 장면의 단일 실행 | 설정                      | 소요 시간 | MLX 최대 할당 |
| --------------------- | ------------------------- | --------- | ------------- |
| 처음 만든 표준 영상   | 640×368, 81프레임, 20단계 | 392.01초  | 측정하지 않음 |
| 기존 초안             | 512×288, 33프레임, 12단계 | 44.72초   | 27.76GiB      |
| 메모리 개선 후 초안   | 512×288, 33프레임, 12단계 | 53.55초   | 13.58GiB      |

2026-11-15 M5 Pro 48GB에서 측정했습니다. 마지막 두 실행은 같은 프롬프트와 seed 42를 사용했습니다. 작은 구역으로 나눠 복원해 메모리는 약 51% 줄었지만 시간은 약 9초 늘었습니다. 표준과 초안의 시간 차이는 품질 설정도 바꾼 결과이며 같은 품질에서의 가속 수치가 아닙니다. 캐시와 기기 상태가 영향을 주는 단일 실행 결과입니다. MLX 할당량은 전체 시스템 메모리나 다른 앱의 사용량과 다릅니다.

- T5 인코더의 가중치를 공식 Wan 설정과 같은 bfloat16으로 유지하고 영상 복원을 작은 구역으로 나눕니다
- 모델 작업은 한 번에 하나만 실행합니다. 중복 요청은 모델을 추가로 올리기 전에 거절하며, 완료 후 자식 프로세스 종료로 모델 메모리를 반환합니다
- CPU 작업의 우선순위와 ffmpeg 스레드 수를 낮춥니다. 영상 생성은 작업실에서 중단할 수 있습니다
- 원고 저장은 마지막 입력 후 500ms에 한 번 처리하고, 화면 이탈과 새로고침 때 마지막 내용을 저장합니다
- 같은 영상 상태는 작품 객체를 다시 만들지 않습니다. 숨긴 탭은 조회를 쉬며 다음 조회는 10초 간격입니다
- 이어쓰기는 최근 6개 장면만 전송하고, 첫 장면 뒤의 영상과 음성은 필요할 때 불러옵니다
- 외부 웹 폰트 요청을 제거하고 설치된 한글 글꼴을 사용합니다

`mx.set_memory_limit`은 엄격한 상한이 아닌 할당 가이드입니다. 이를 20GB 메모리 제한이 보장된다고 해석하지 않습니다. [MLX 문서](https://ml-explore.github.io/mlx/build/html/python/_autosummary/mlx.core.set_memory_limit.html), [공식 Wan T5 설정](https://github.com/Wan-Video/Wan2.1/blob/main/wan/configs/shared_config.py)

## 저장과 복구

원고는 브라우저의 `story-studio.library.v1`에 최대 50개 작품까지 저장합니다. 저장본 손상, 용량 초과와 다른 창의 수정을 알리고 원본을 보존합니다. 브라우저 데이터를 지우기 전에 작품 JSON을 백업하세요.

개인 생성 파일은 앱의 `.data/assets`, 영상 상태는 `.data/tasks`, 모델과 설치 환경은 `.data/local`에 있습니다. `STORY_STUDIO_DATA_DIR`로 전용 저장 폴더를 지정할 수 있습니다. 이 폴더, 로그, 모델 가중치와 `.env.local`은 Git에서 제외됩니다.

목소리 이름과 녹음별 대본은 `.data/voices`, 학습 실행과 가중치는 `.data/voice-training/runs`에 저장합니다. 목소리를 다른 컴퓨터로 옮길 때는 두 폴더와 `.data/assets`, 동일 revision의 Base 모델을 함께 보존하세요. 작품 JSON 백업에 목소리 가중치는 포함되지 않습니다.

**JSON에는 미디어 자체가 포함되지 않습니다.** 다른 컴퓨터로 옮길 때 JSON과 `.data/assets`를 함께 백업하거나 PNG, MP4와 WAV를 별도로 받으세요. 작품 삭제는 브라우저 원고만 지우며 생성 파일을 자동으로 삭제하지 않습니다.

영상 생성은 Python 프로세스가 진행 상태와 결과를 디스크에 원자적으로 저장합니다. 새로고침 뒤에는 기존 작업을 조회합니다. 서버 재시작 중에도 이미 시작한 비동기 영상 프로세스는 진행할 수 있지만 컴퓨터 종료나 강제 종료는 복구 실행되지 않습니다. 종료된 작업은 실패로 표시하고 새로 생성할 수 있습니다. 조회의 일시적 실패 때는 새 요청 없이 기존 작업을 다시 확인합니다. 모델 실행 제한과 자동 확인 제한은 60분입니다.

실행 중에는 `HF_HUB_OFFLINE`, `TRANSFORMERS_OFFLINE`을 적용하고 원격 코드 실행을 끕니다. 기본 로컬 모드에 외부 내용 심사 API는 없습니다. 모델에 학습된 응답 거절 성향은 남을 수 있으며 모든 콘텐츠에 대한 응답을 보장하지 않습니다. 기존 클라우드 어댑터는 명시적으로 `STORY_STUDIO_PROVIDER=cloud`일 때만 선택합니다.

## Qwen에 직접 질문하기

일반적인 기본 설치에서 앱 폴더를 연 뒤 실행합니다. 작업실의 원고용 시스템 지시문과 JSON 응답 제약을 사용하지 않습니다.

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
.data/local/.venv/bin/python -m mlx_vlm.generate \
  --model .data/local/models/text \
  --prompt "한국어로 답해줘. 여기에 원하는 질문을 입력하세요" \
  --thinking-mode disabled --max-tokens 512
```

연속 대화는 `--chat`을 덧붙입니다. 이 명령은 작업실과 별도의 모델 프로세스를 실행하므로 작업실의 생성이 끝난 뒤 사용합니다. 저장 경로를 바꿨다면 가상환경과 모델 경로도 같은 경로로 지정하세요.

## 검증

```sh
yarn workspace @side/story-studio check
yarn workspace @side/story-studio test:e2e --workers=2
yarn workspace @side/story-studio build
```

모델 없는 Python 작업 상태 검사는 `python3 -m unittest discover -s projects/story-studio/apps/web/scripts/local -p worker_test.py`로 실행합니다. Apple Silicon에서는 앱 폴더에서 `.data/local/.venv/bin/python -m unittest discover -s scripts/local -p '*_test.py'`로 실제 MLX 어댑터의 가중치 변경, 기본 가중치 보존, 옵티마이저 복원과 재개 결과 일치까지 검증합니다. 별도 데이터 경로를 쓴다면 가상환경 경로도 맞춰 주세요.

Vitest는 로컬 기본값, 키 미전달, 오프라인 환경, 동시 생성 차단, 프로세스 중단, 실패 후 재시도, 원고 검증, 자산 범위 요청과 상태 변경 시의 참조 보존을 확인합니다. 모델 계산은 가벼운 자식 프로세스나 모의 응답으로 대체합니다. Playwright는 별도 포트 3411, `.e2e-build`, 별도 저장 폴더에서 모바일과 데스크톱의 편집, 백업, 실패 복구, 영상 및 음성 재생을 확인합니다.

실제 모델로 만든 [공개 예시](apps/web/public/examples/project.json)는 약 13.4초의 한국어 음성 및 자막 포함 MP4입니다. Qwen 원고, Qwen3-TTS 음성과 Wan의 생성 프레임을 ffmpeg로 합쳤으며 정지 이미지 이동 효과로 대체하지 않았습니다. 모델의 미적 품질이나 인물 일관성에 대한 광범위한 평가는 하지 않았습니다.

첫 오프라인 화면 검사에서 Google Fonts 요청이 확인됐고 외부 폰트를 제거한 뒤 다시 검사했습니다. 추가 검사 결과와 최신 CI 상태는 PR에 기록합니다. 모델 가중치는 CI에서 다운로드하지 않습니다.

## 행동 측정과 접근 경계

로컬 기본 설정은 측정 키가 없어 SDK를 로드하거나 이벤트를 전송하지 않습니다. 측정을 명시적으로 구성한 경우에만 `landing_start_clicked`, `studio_opened`, `studio_request_clicked`, `studio_request_succeeded`를 보냅니다. 속성은 고정된 진입 종류와 작업 종류뿐이며 원고, 제목, 인물, 파일명, 경로와 사용자 ID를 수집하지 않습니다. 영상의 HTTP 제출 성공은 영상 계산 완료와 구분합니다.

이 앱은 127.0.0.1에 바인딩된 개인용 도구입니다. 네트워크 공개, 공동 작업과 로그인은 이번 범위에 포함하지 않습니다. 공개 서비스로 전환하려면 인증과 작품 소유권을 별도로 설계해야 합니다.
