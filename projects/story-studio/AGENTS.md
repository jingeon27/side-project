# Story Studio

- 사용자 요청: 영화·드라마·짧은 애니메이션, 웹툰, 소설을 한국어로 만드는 독립 창작 스튜디오다.
- 소개(`/`)와 작업실(`/studio`)을 구분한다. 소개는 간결한 설명과 시작 동선, 작업실은 입력·편집·작품 관리에 집중한다.
- 첫 디자인의 짙은 배경·따뜻한 포인트 색상은 유지한다. 디자인 스킬 적용만으로 배치를 갈아엎지 않는다. 짧은 제목·버튼·문구 끝에는 마침표를 붙이지 않는다. 안내·오류의 완전한 문장은 자연스럽게 쓴다.
- 원고는 브라우저 저장, 생성 자산·영상 작업은 이 앱의 `.data`가 소유한다. 비밀키를 브라우저로 보내지 않는다. 네트워크 공개·다중 사용자 서비스로 전환하려면 인증·작품 소유권·저장소를 별도 설계해야 한다.
- API 계약은 `apps/web/src/lib/story.ts`에서 검증한다. 이미지·영상은 원고와 별도 명시적 요청으로 생성하며, 유료 제출을 자동 재시도하지 않는다.
- 생성 기능을 모의 응답으로 검증한 결과와 실제 모델 호출 검증을 구분해 보고한다.
- 기본 실행은 API 키 없는 로컬 모드다. 모델은 이 앱 전용 경로에 두고 실행 중 외부 생성 서비스를 호출하지 않는다. 현재 지원 대상은 Apple Silicon Mac이다.
- MLX 모델 실행은 한 번에 하나만 허용하고 작업이 끝나면 프로세스와 모델 메모리를 해제한다. 기본 영상은 낮은 부하의 초안 품질이며 표준 품질은 사용자가 선택한다. 영상 작업 상태는 Python 프로세스가 디스크에 보관한다.
- 실제 생성한 공개 예시는 `apps/web/public/examples`에, 개인 원고·모델 가중치·설치 환경·진단 로그는 Git에서 제외된 `.data`에 둔다. 다른 프로젝트의 모델이나 프로세스를 변경하지 않는다.
