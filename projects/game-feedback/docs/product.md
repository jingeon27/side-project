# 제품 범위

Game Feedback은 플레이어가 구체적인 플레이 고민과 당시 게임 정보를 공유하고 다른 사용자의 조언을 받는 서비스다. 첫 카테고리는 클래시로얄이다. 핵심 가설은 조언을 원하는 사용자와 보상 없이 조언할 사용자가 함께 존재하며, 유용한 답변을 받은 사용자가 다시 방문한다는 것이다.

## 게임과 게시판

홈은 게시판의 글을 최신순으로 모은 피드다. 게임마다 **피드백, 친추판매, 친선전 모집, 게임코치, 자유게시판** 다섯 종류를 공통으로 사용한다. 피드백과 게시판을 서로 다른 상위 메뉴로 분리하지 않는다. 게임은 카테고리, 게시판은 공통 board 종류로 저장하며 게임마다 메뉴나 화면을 복제하지 않는다. 계정 거래는 제공하지 않는다.

글쓰기에서는 글의 종류를 **분류**로 표시한다. 어느 게임 메뉴에서 시작해도 해당 분류를 기본 선택하며, 등록 전에 공통 다섯 분류 사이에서 변경할 수 있다. 분류를 바꿔도 제목과 서식 본문, 선택한 게임은 유지하고 분류별 금액 입력만 전환한다.

친추판매는 원화 판매 금액을 별도 입력하고 저장한다. 피드·게시판 카드와 상세에서 금액을 확인하고 작성자가 수정할 수 있다. 비워두면 가격 협의로 표시하며 기존 글의 가격 미등록 상태와 구분한다. 모든 게임에서 같은 계약을 사용한다.

게임코치는 유료 강의와 코칭의 양방향 모집이다. 코치가 수강생을 모집할 수도 있고 수강생이 코치를 구할 수도 있다. 시간당 수강료/희망 수강료를 원화로 입력하거나 채팅에서 협의한다. 작성글의 역할과 금액을 카드와 상세에 표시하고 1:1 채팅으로 연결한다. 결제, 정산, 예약 확정이나 수강 완료 상태를 만들지 않는다.

공개 API는 `FEEDBACK`, `FRIEND_SALE`, `FRIENDLY`, `COACHING`, `FREE`를 받는다. 폐지한 게시판의 기존 데이터는 보관하되 목록·검색·상세·프로필 집계·알림·사이트맵에서는 제외한다. 별도 데이터 삭제나 기존 글의 자동 재분류는 수행하지 않는다.

## 첫 경험

1. Google의 `openid`로 로그인한다. 가입자는 서비스 닉네임을 직접 정하고 연령 정책·약관·개인정보 안내에 동의한다.
2. Player Tag를 입력해 프로필을 확인한다. 공식 계정 소유권 검증 전에는 `UNVERIFIED`로 표시한다.
3. 피드백 요청을 작성한다. 이때의 기본 게임 프로필을 요청의 스냅샷으로 보존한다.
4. 다른 사용자가 답변과 댓글을 남긴다. 작성자는 자신의 콘텐츠를 수정·삭제할 수 있다.
5. 요청자는 인앱 알림으로 답변을 확인하고 유용한 답변에 `도움됨`을 표시한다.

최신순·미답변 목록과 cursor pagination을 제공한다. 무한 목록은 TanStack Query가 관리한다. 피드백 요청/답변과 알림 상태는 서버의 최신 결과를 우선한다. 피드백 답변은 읽음·도움됨의 대상이며 일반 댓글은 보충 대화를 위한 별도 영역이다.

## 1:1 채팅

다른 작성자와 직접 대화를 시작하고 채팅함에서 이어 갈 수 있다. 같은 두 사용자의 대화방은 하나이며 메시지는 새로고침·재로그인 이후에도 보존한다. 새 메시지와 읽음 변경은 실시간으로 갱신하고 대화별 미읽음 수를 보여 준다.

대화와 메시지는 참여자 두 명만 볼 수 있다. 자기 자신과의 대화는 만들 수 없고 차단 관계는 양방향으로 대화 조회·시작·전송·읽음 처리에 적용한다. 읽음은 실제 화면에서 확인한 마지막 메시지까지만 반영해, 그 이후 도착한 메시지가 미리 읽음 처리되지 않도록 한다. 로그아웃·세션 만료 후에는 실시간 연결을 유지하지 않는다.

참여자가 탈퇴하면 그 사용자가 참여한 대화와 메시지를 함께 삭제하며 상대의 채팅함에서도 더 이상 조회할 수 없다. 차단은 데이터 삭제와 별도로 처리해, 차단을 해제하면 유지된 대화를 다시 조회할 수 있다.

채팅은 텍스트와 이미지/동영상을 주고받는 1:1 대화다. 그룹 채팅, 푸시 알림, 메시지 편집·삭제, 종단 간 암호화는 이번 범위에 포함하지 않는다. 채팅 내용을 외부 분석 이벤트에 싣지 않는다. 공개 운영 전에는 개인 대화의 보유·삭제 정책과 악용 신고 절차를 운영 문서에 반영해야 한다.

## 안전한 비공개 알파

신고, 사용자 차단, 운영자의 콘텐츠 숨김, 작성자 권한, 입력 검증·요청 제한, 로그아웃·탈퇴를 기본 범위로 둔다. 운영자는 권한으로 보호되는 API를 통해 카테고리와 신고를 관리한다. 초기 카테고리를 DB seed로 제공하며 일반 사용자는 추가할 수 없다.

서비스는 Supercell의 공식 서비스가 아니다. Player Tag 조회 성공은 계정 소유권 증명이 아니다. 공개 전 팬 콘텐츠 정책, 서비스 이름·도메인, 연령 정책, 약관·개인정보 문서와 운영 연락처를 실제 운영 주체 기준으로 확인해야 한다.

## 테스트 계정과 사용자 인증 표시

정해진 테스트 계정을 선택해 실제 서비스 세션으로 전환한다. 테스트 계정은 명시적 데모 환경에서만 제공하며, 게시글·댓글·채팅을 DB에 저장된 해당 사용자로 작성한다. 계정 전환 후에는 선택한 사용자가 참여한 비공개 대화만 볼 수 있다. 테스트 계정과 테스트용 인증 예시는 화면에 구분해 표시한다.

사용자의 서비스 인증 표시와 게임 계정 소유권은 별개다. 일반 Google 가입자는 서비스 인증이 없는 상태로 시작하고, 운영자 권한이 있는 경로만 인증 상태를 변경한다. 테스트용 인증 사용자도 실제 인증 완료 사용자로 표현하지 않는다. 게임 프로필은 계속 `UNVERIFIED`이며 Player Tag 조회나 서비스 인증 배지가 소유권을 증명하지 않는다.

대표 Supercell Player Tag를 사용자 정보에 저장하고 조회에 성공한 게임 계정 정보와 함께 갱신한다. 태그는 `#`을 포함한 대문자로 정규화한다. 외부 조회에 실패하면 기존 태그와 연결을 유지한다. 프로필 변경은 이미 작성한 요청의 게임 스냅샷을 소급 변경하지 않는다.

## 제품 검증

North Star Metric은 주간 유효 피드백 성사 건수다. 우선 요청자가 `도움됨`으로 표시한 답변이 하나 이상 있는 요청을 유효 피드백으로 본다. 같은 요청의 여러 도움됨 답변을 별도 성사 건수로 중복 집계하지 않는다.

초기 모집은 피드백 요청자 10명 인터뷰 또는 모집, 제공자 5~10명 확보 시도로 시작한다. 기존 커뮤니티에서 수동 매칭하고 첫 답변 소요 시간을 기록한다. 출시 후 요청 30건, 24시간 내 첫 답변율, 도움됨 비율, 재방문율을 측정한다. 이는 검증 목표이며 확보된 성과가 아니다.

## 후속 범위

영어·일본어 완성, 게시글/답변 번역과 캐시, Sentry·Amplitude 및 서버 AnalyticsEvent, 평판·팔로우·제공자 프로필, 소유권 인증 챌린지, 네이티브 앱 운영·스토어 출시, 게임 확장은 후속 단계다. WebView 모바일 셸은 사용자 추가 요청에 따라 구현했으며 웹과 같은 테스트 계정·게시글·댓글·채팅을 사용한다. `/ja`, `/en` 경로가 존재하는 것만으로 글로벌 출시가 완료된 것으로 간주하지 않는다. 이메일 알림은 별도 주소 수집·동의·검증 후 도입한다.
