# Social login marks

These marks identify the corresponding sign-in providers. They are not service logos or decorations.

- Google: original `g-logo.png` from https://developers.google.com/identity/branding-guidelines and https://developers.google.com/static/identity/images/g-logo.png.
- Kakao: unmodified symbol path from the official login preview, framed to its symbol bounds: https://developers.kakao.com/tool/images/resource/preview/login-complete-ko.svg. Button guidance: https://developers.kakao.com/docs/ko/kakaologin/design-guide.
- Discord: official Symbol SVG from https://discord.com/branding. Preserve the logo path and aspect ratio.
