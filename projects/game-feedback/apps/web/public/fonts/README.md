# Social preview font

`NotoSansKR-Social.woff` is derived from Google Fonts' Noto Sans KR, instantiated at weight 600 and subset for Latin, Korean, Japanese, CJK ideographs and punctuation. It is used only when rendering detail Open Graph images.

Source: https://github.com/google/fonts/tree/main/ofl/notosanskr

The original copyright notice and SIL Open Font License 1.1 are retained in `OFL.txt`.
