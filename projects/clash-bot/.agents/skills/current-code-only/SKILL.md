# legacy 없이 현재 코드로만 동작한다

clash-bot은 지금 저장소에 있는 코드와 현재 형식의 기록만으로 동작한다. 예전 버전이 남긴 기록·모델·판단 계약·실행 경로를 계속 읽거나 실행하기 위한 코드를 두지 않는다.

## 현재 운영 경로

- arena 자가대국(`arena start|status|stop` 등). 리그는 정책 형식마다 새 폴더(`<규칙 ID>-<형식 키>`)에서 시작한다.
- 명시적으로 승인된 로컬 트로피 자동개선(`trophy status|serve`, `TrophySession`). 현재 화면·확인된 내 행동·두 번 일치한 결과로만 별도 CPU 정책을 학습한다. 새 `trophy-own-trajectory-v1`의 학습 역할만 사용하고 이전 읽기 전용 기록을 변환하지 않는다. 평가 경기는 고정 모델·동일 선택 분포로 두며 채택 증거와 모델을 다른 실행 경로와 격리한다. 감독이 넘긴 시뮬레이터 챔피언(`trophy-simulation-candidate-v1`)은 같은 실전 게이트로만 채택한다.
- 자가개선 감독(`loop start|status|stop`). 자가대국 유지·재시작 한도·챔피언 인계·패치 확인·보고만 하며 실전 경기를 시작하지 않는다.
- Git 밖 화면 어댑터가 이름으로 실행하는 `clash_bot.qwen.action_prior serve`와 인식 워커(`vision_worker`, `trophy_vision`). 이들이 읽는 decision-v3 문자열, 자산·데이터 경로(`assets/counterpush`, `.data/counterpush/detector`, `profiles/counterpush.json`)와 `rulesID`에 들어가는 계약 키(`liveDeck: "counterpush"`, `counterpushCalibrated`)는 운영 계약이며 legacy가 아니다.

이 목록에 없는 경로는 기존 사용자의 명시적 요청·승인 범위를 먼저 확인한다. 이미 승인된 로컬 트로피 화면 실험을 세션마다 다시 확인하지 않는다. 명시된 범위가 없을 때에만 새 경로를 만들기 전에 사용자에게 확인한다. 로컬 실험과 공개 실행 경로·실전 학습·채택 증거를 구분한다.

## 규칙

- 예전 형식을 받아들이는 분기, 없는 필드의 기본값 대체, 필드 별칭, 자동 변환(마이그레이션)을 추가하지 않는다.
- 저장 파일은 현재 스키마로 검사한다. 맞지 않으면 경로와 이유를 밝히고 멈춘다. 기존 `.data`를 고치거나 지울지는 사용자가 정한다.
- 형식·계약·모델·실행 경로를 바꾸면 같은 변경에서 이전 구현과 테스트·스크립트·문서를 함께 지운다. 나중에 지울 코드나 쓰지 않는 export를 남기지 않는다.
- TS와 Python이 함께 읽는 계약(`contracts/`, `test-fixtures/`의 공유 사례)은 양쪽을 같이 바꾼다. 한쪽만 예전 값을 받아들이게 두지 않는다.
- 운영 중인 모델이나 Git 밖 어댑터가 쓰는 계약은 legacy가 아니다. decision-v3 직렬화는 `action_prior`가 읽는 동안 유지한다. 아무 실행 경로도 쓰지 않게 되면 그때 지운다.
- 보고할 때는 지운 경로와, 새 형식과 맞지 않아 멈출 수 있는 기존 기록을 함께 적는다.

## 행동 정책을 바꿀 때의 회귀 기준

- 수읽기의 루트와 학생은 같은 화면 표본·타워 가림 관측을 사용한다. 개선이 없는 교사는 실전 정책과 같은 행동 이력이어야 한다. 미래 노드에서도 후보 수 축소가 카드 확률을 바꾸지 않는지 확인한다. 전부 계산하지 않는 경우 포함 확률과 근사 범위를 밝힌다. 탐색 잡음으로 원래 정책의 최선 위치를 비교 목록에서 지우지 않는다.
- 가상 상대는 저장한 빠른 정책의 카드·위치 선택을 따른다. 내 수의 가치가 바뀌었다고 상대 행동을 별도 PUCT로 최적화하지 않는다. 교사 진단 성적과 별도 시드의 학생 채택 성적을 구분한다.
- 수읽기는 각 진영의 판단 시점에 공개 전장을 읽고 입력을 수락한다. 동시 입력은 같은 배치 전 상태를 사용한다. 확인한 실행 틱에서 입력 지연을 빼서 추정한 상대 시점이나 가설 시점을 같은 비교에 유지하고, 반올림 전 좌표로 짧은 구간의 이동을 계산한다.
- 전술 연습은 학습에만 정해진 공격을 노출한다. 타이밍과 엘릭서가 맞아 실제로 실행된 공격과 카드별 비교 기회를 기록한다. 유사한 좌표 여러 개를 전술 다양성으로 세지 않고, 기존 기준 위치와 떨어진 대안을 함께 평가한다.
- 자가대국의 교사는 현재 기준 챔피언으로 고정한다. 학습 후보는 평가 통과 전 교사·과거 상대 풀에 넣지 않는다. 초기 기준 이외의 상대 풀 입장은 승리·대기 교착 검사를 모두 통과한 채택 경로가 소유한다. 후보 가중치와 재생 자료의 누적 학습은 계속하며 교사 변경과 구분한다.

- 스킬 준비 상태를 사용 가치로 취급하지 않는다. 빈 필드·2 엘릭서에서 대기/스킬만 남은 상태와 여러 위치 후보/대기 하나의 확률 편향을 검사한다. 명시적 사전 보정과 실제로 학습한 판단을 보고에서 구분한다.
- 빠른 정책은 카드별 주변 확률을 먼저 비교하고 그 카드 안의 위치를 고른다. 한 카드의 위치가 늘어났다고 각각을 대기 하나와 바로 argmax 비교하지 않는다. 탐색 후보를 줄일 때 카드별 전체 확률을 보존하고, 방문하지 않은 위치를 0점 정답으로 만들지 않는다. 채택 전에 고정 후보끼리 대국해 카드 배치 없이 끝나는 교착도 검사한다. 대기 제거·강제 카드 사용이나 카드 사용량 보상으로 이 검사를 우회하지 않는다.
- 학습 후보를 줄일 때도 전체 후보의 카드별 확률 질량과 기울기를 보존한다. 생략한 위치의 현재 로짓까지 미분하고, 대표 위치 하나에 카드 전체의 갱신을 몰아주지 않는다. 실제 저장한 관측의 기준 정책에서 두 타워 관측의 정답을 따로 만들며, 정답 KL과 실제 가중치 갱신 후의 전체 후보 KL을 구분한다.
- 학습 후보의 값과 전체 후보의 카드별 확률 질량을 함께 확인한다. 같은 고정 가중치가 전체 후보와 학습 부분집합에서 다른 카드 확률을 내는지 검사하고, 타워 정보를 가렸을 때의 정규화도 따로 저장한다. 수집 시점의 고정 분할 보정이 이후 가중치에서도 정확하다고 확대하지 않는다.
- 낮은 예산의 강제 탐색 횟수를 곧바로 좋은 행동의 정답 확률로 삼지 않는다. 방문 기록과 학습 정답을 분리하고 기존 정책·관측한 수읽기 평가·변화 제한을 함께 기록한다. 정답의 추정 가치 증가와 실제 승률 개선을 구분한다. 진단에 본 평가 시드를 새 규칙의 정식 평가에 재사용하지 않는다.
- 선택 확률을 보정하면 실제 선택·저장 확률·PPO가 같은 분포를 사용하게 한다. 고정 특징 캐시를 정책 확률 캐시로 바꾸지 않는다.
- 피해·처치 예측은 이동·배치 지연·독 체류 시간과 체력의 관측 여부를 포함한다. 모르는 체력을 최대 체력으로 채우거나 현재 접촉 수를 실제 피해로 부르지 않는다. 후보 위치 변경은 급한 수비와 빈 필드 빌드업을 각각 확인한다.
- 오두막에 일반 유닛의 타워 앞·옆 배치를 붙이지 않는다. 건물 유인·활성 범위와 기존 건물·상대 독을 비교하고, 통은 굴러가는 경로로 검사한다. 가능한 이동의 피해 상한을 실제로 맞힐 궤적 가치로 쓰지 않는다.
- 무덤·독은 좌표뿐 아니라 필드, 남길 엘릭서, 상대 순환의 수비 카드 가능성, 중복 주문과 킹타워 활성화 위험을 함께 확인한다. 타워 체력·상대 패를 읽지 못하면 불명으로 남기고 실전에서 확인했다고 보고하지 않는다.
- 상대 시점을 내 시점으로 옮길 때는 강 중앙 기준 180도 회전으로 가로·세로 좌표와 속도, 좌우 라인과 효과 예측점을 모두 바꾼다. 위아래 반사만 한 표본은 재사용하지 않는다.
- 빈 필드의 선패는 급한 수비와 분리한다. 타워·장식을 유닛으로 읽지 않는지, 킹타워 뒤의 실제 배치 가능 공간이 좌표 제한으로 앞으로 밀리지 않는지 확인한다. 잔량이 적을 때 의미 없이 용광로를 순환하지 않으며 기사·용광로 진화 카운터와 남길 수비 자원을 판단 입력에 전달한다.
- 로켓병은 독 체류 피해, 바통 궤적과 뒤따르는 바바리안, 중앙 유인 후 타워 수비를 비교한다. 바통 굴림 피해만으로 항상 처치한다고 간주하지 않는다. 상대 카드 종류·체력·공격 대상이 불명이면 정교한 완막을 확인했다고 보고하지 않는다.

- 보정한 무덤 후보에 타워 정중앙 fallback을 다시 붙이지 않는다. 바깥쪽 효과의 큰 관측 박스가 정중앙까지 정답으로 묶지 않는지 실제 정답 ID를 검사한다.

- 빠른 실전 정책과 네이티브 탐색·평가·학습에 다른 전투 보정을 적용하지 않는다. 선택 로짓의 사전 보정은 같은 값으로 저장·학습하고 학습 성과와 구분한다. 왼쪽 기사가 올 때 오른쪽 바통을 쓰는 장면, 지원·수비 예산 없는 첫 무덤을 회귀 기준에 포함한다.
- 드릴 수비 가치는 해당 드릴·주변 고블린의 예측과 연결한다. 다른 라인의 적을 때린 통을 드릴 수비로 계산하지 않고, 같은 라인에서도 굴림 방향과 바바리안 도착점을 확인한다. 모르는 체력을 낮은 체력으로 취급하지 않는다. 등장 시계와 관측된 몸체를 구분하며, 트랙을 처음 본 뒤 지난 시간을 등장 지연으로 대체하지 않는다. 근처에 오두막이 있다는 이유만으로 드릴이 막혔다고 간주하지 않는다.
- 통의 가로 폭과 앞뒤 길이를 같은 값으로 두지 않는다. 고정 표의 충돌 반폭을 각각 확인하고 시간 표본이 굴림 끝을 넘지 않는지, 통을 적 바로 위·반대편에 쓰는 것과 아래에서 관통시키는 것의 실제 시뮬레이션 피해 차이를 검사한다.
- 실전 배치 검증에는 빈 필드의 전방·가장자리 배치, 킹타워 뒤 선택지, 급한 수비의 가까운 배치를 함께 포함한다. 직접 확인된 내 건물 입력과 연속된 화면 검출로 소속·바닥 위치를 연결할 때는 원래 검출과 연결 근거를 남긴다. 화면 재생에서 선택이 바뀐 결과를 새 실전 승리나 모델 향상으로 보고하지 않는다.
- 수읽기의 가상 미래 상대 행동은 실제로 관측한 플레이와 구분한다. 이후 배치가 없는 짧은 수비 비교를 반격 학습으로 보고하지 않는다.
