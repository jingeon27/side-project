# legacy 없이 현재 코드로만 동작한다

clash-bot은 지금 저장소에 있는 코드와 현재 형식의 기록만으로 동작한다. 예전 버전이 남긴 기록·모델·판단 계약·실행 경로를 계속 읽거나 실행하기 위한 코드를 두지 않는다.

## 현재 운영 경로

- Counterpush 후보 학습·고정 평가·채택. 모델은 Qwen3.8-27B 하나다. 챔피언은 자기 체크포인트의 판단 계약으로(`controller_version`이 없으면 controller 1), 후보는 controller 3으로 둔다.
- BlueStacks 트로피 관찰 플레이. 학습·평가에 넣지 않는다.
- Android 기기 설정·인식 확인 명령, 규칙 봇(`observe`·`play`), 학습 없는 Qwen 단일 경기(`qwen`).
- arena 자가대국과 `arena study`.

이 목록에 없는 경로를 새로 만들거나 지운 경로를 되살리려면 먼저 사용자에게 확인한다.

## 규칙

- 예전 형식을 받아들이는 분기, 없는 필드의 기본값 대체, 필드 별칭, 자동 변환(마이그레이션)을 추가하지 않는다.
- 저장 파일은 현재 스키마로 검사한다. 맞지 않으면 경로와 이유를 밝히고 멈춘다. 기존 `.data`를 고치거나 지울지는 사용자가 정한다.
- 형식·계약·모델·실행 경로를 바꾸면 같은 변경에서 이전 구현과 테스트·스크립트·문서를 함께 지운다. 나중에 지울 코드나 쓰지 않는 export를 남기지 않는다.
- TS와 Python이 함께 읽는 계약(`contracts/`, `test-fixtures/`의 공유 사례)은 양쪽을 같이 바꾼다. 한쪽만 예전 값을 받아들이게 두지 않는다.
- 운영 중인 모델이 쓰는 계약은 legacy가 아니다. controller 1은 챔피언 v68이 쓰는 동안 유지한다. 챔피언이 바뀌어 아무 모델도 쓰지 않으면 그때 지운다.
- 보고할 때는 지운 경로와, 새 형식과 맞지 않아 멈출 수 있는 기존 기록을 함께 적는다.
