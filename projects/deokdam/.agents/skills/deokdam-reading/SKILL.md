# 덕담집 풀이

입력한 고민과 오늘 해볼 행동이 화면에서 바로 이어지는지 확인한다. 취준생은 본인이 해볼 일, 부모는 자녀에게 건넬 말, 수험생은 성적과 발표를 앞두고 할 일을 찾으러 온다. 풀이 결과 위에 기술 설명이나 구매 안내를 먼저 쌓지 않는다.

- [풀이 화면](../../../apps/web/src/features/reading/PersonalReading.tsx)과 [계약](../../../apps/web/src/features/reading/contracts.ts)을 함께 본다. 양력·음력과 출생 시각 미상 사례를 보존한다. 경험은 어떤 일이 있었고 어떻게 행동했는지 한두 문장 예를 든다. 생년월일과 경험 원문은 브라우저에 두고, 요청·분석 이벤트에는 제품 계약에서 허용한 값만 쓴다.
- [참고 자료](../../../apps/web/src/features/reading/knowledge/corpus.ts)는 SQLite 벡터 검색으로 후보를 고르고 Qwen은 후보 ID를 고른다. 풀이 문장과 기록장에 남길 행동은 선택한 같은 자료에서 가져온다. 모델 입력을 바꿀 때는 세 유형의 실제 응답과 이전에 저장된 풀이의 화면을 함께 확인한다.
- 결과에 네 기둥과 일간의 뜻을 드러내고, 월지로 읽은 계절과 고른 고민에 맞춘 실천 예를 설명한다. 시각 미상이나 절기 경계에서 정할 수 없는 기둥은 미상으로 둔다. Qwen의 선택과 검수 문장을 구분하고 결과를 예측·과학적 진단으로 표시하지 않는다. 계정 기록에는 사용자가 저장한 실천과 메모만 담고 출생 입력은 전송하지 않는다. 모바일에서는 좁은 화면에서 입력과 제출 영역이 겹치는지 보고, 처리 중이나 실패 뒤 사용자가 입력을 잃지 않는지 확인한다. 분석은 요청, 성공, 근거 열기, 기록 저장을 기존 이벤트 카탈로그에서 확인한다.
- 기본 기능은 [프로젝트 검사](../../../README.md)를 따른다. 운영에서 응답이 느리면 [공용 EC2 배포 안내](../../../deploy/shared-instance/README.md)를 열어 메모리, CPU와 첫 요청·재요청 시간을 측정한다. 캐시 응답과 실제 Qwen 응답을 구분하고 기존 서비스의 공개 응답을 같이 확인한다.
