# 덕담집 쇼츠

웹 카드에서 실천할 행동 하나를 찾고, 그 행동으로 인물의 하루에 생긴 구체적인 변화를 30초 안에 보여준다. 주인공은 취준생, 자녀를 기다리는 부모, 대입 수험생 가운데 회차에 맞는 한 명으로 정한다.

1. 프로젝트의 [공개 카드 목록](../../../apps/web/src/shared/episodes.json)에서 제목, 고민, 덕 행동, 메시지, 도착 경로를 확인한다. 새 회차는 먼저 공개 카드를 만들고 행동 문구를 맞춘다. 같은 이야기를 다른 사람 시점으로 풀 때는 시간, 관계, 이미 아는 사실을 일치시킨다.
2. 첫 장면은 짧은 말이나 실제 행동으로 연다. 기다리던 알림, 지운 메시지, 건넨 대답처럼 앞 장면에서 이어지는 사건을 고른다. 인물 입으로 화면의 행동을 다시 읽는 부분은 덜어낸다. 〈백 번째 지원서〉는 친구와 첫 줄을 바꿔 읽다가 잊고 있던 경험을 다시 쓰는 이야기다.
3. 창작 상황극 표시는 첫 장면부터 넣는다. 실제 후기를 쓸 때는 공개 동의와 본인이 제공한 사실을 확인한다. 광고와 복채로 합격이 바뀐다는 인과나 예측을 쓰지 않는다.
4. 얼굴, 손, 상대의 반응처럼 컷마다 관객이 봐야 할 대상을 하나 정한다. 휴대폰을 내려놓거나 보낸 문장을 다시 지우는 동작이 다음 컷의 표정이나 대사로 이어지게 한다. 원화와 영상의 처음·중간·끝에서 옷, 손의 위치, 중요한 소품을 대조한다. 손이 화면을 가리거나 인물과 소품이 바뀌는 구간은 잘라내거나 원화를 고친 뒤 해당 컷만 다시 만든다.
5. [제작 절차](references/production.md)에 따라 소리를 끈 완성본에서 누가 무엇을 했는지 확인하고, 소리를 켜서 말이 내레이션이나 자막과 중복되는 곳을 덜어낸다. 망설임은 실제로 읽을 수 있는 표정과 침묵으로 남긴다. 제목은 첫 장면에 넣고, 실제 웹 카드는 이야기의 끝에서 행동 한 문장을 읽을 수 있게 보여준다. 검수한 MP4, 표지, SRT, 게시 문구, 웹 카드 경로를 전달한다.
6. 제목과 웹 카드 이름을 맞추고 끝 장면에 채널 프로필에서 찾을 이름을 표시한다. YouTube 게시가 요청되면 채널과 공개 범위를 확인하고 게시한다. 사실적으로 생성한 장면을 쓰는 편의 게시 초안에는 YouTube AI 사용 공개 항목을 남긴다.
