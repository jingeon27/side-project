# 덕담집

- 쇼츠에서 보여준 행동과 공개 카드 문구는 `apps/web/src/shared/episodes.json`을 기준으로 맞춘다. 쇼츠 제작은 [deokdam-shorts](.agents/skills/deokdam-shorts/SKILL.md)를 사용한다.
- 덕은 실제로 해본 행동을 기록한다. 광고 보상은 보너스 풀이이며 복채는 7일 리포트의 가격이다. 창작 에피소드는 상황극으로 표시한다. 서비스와 홍보에는 합격 예측이나 보장 표현을 넣지 않는다.
- 생년월일, 달력 유형, 출생 시각은 브라우저가 계산에 사용한다. 선택 입력한 과거 경험의 원문도 브라우저에 둔다. 서버 풀이에는 선택지, 일간의 오행, 미리 정의한 경험 주제만 보내며 광고·Amplitude에 출생 정보와 경험 원문·주제를 전달하지 않는다. 부모는 본인 정보를 사용한다.
- 사주 모델은 실행 호스트의 루프백이나 덕담집 전용 Docker 네트워크에서만 호출한다. 모델은 자료 후보에서 실천을 고르고, 화면은 검수한 풀이와 조언 문장을 사용한다.
- 무료 기록은 현재 브라우저가 소유한다. 주문과 구매 권한은 서버가 소유한다. 결제 응답을 포트원에서 조회해 서버 주문과 대조한 뒤 발급한다.
- 로컬 실행과 검증, 운영 연동은 [README](README.md)를 따른다.
